# OLAP Turbo

列式 OLAP 查询加速引擎：列裁剪、谓词下推与向量化执行。

## 范围

本仓库从零开始实现上述方向的可用工具，不依赖外部同类实现。

## 状态

首个可查询基线已落地：列裁剪、谓词下推与按批向量化执行。

## 用法

```
python -m olap_turbo --data-dir <目录> --query <SQL>
```

- 表为目录中的 CSV 文件，表名取去掉 `.csv` 的文件名；首行为列名，后续每行为记录。
- 表名与列名只接受简单标识符。
- 支持两类查询：
  - `SELECT 列, ... FROM 表 [WHERE 条件]`
  - `SELECT count(*) [, sum(列) ...] FROM 表 [WHERE 条件]`
- WHERE 条件由 `=`、`!=`、`>`、`>=`、`<`、`<=` 比较组成，以 `AND` 组合；
  比较值为不带引号的数字（按十进制数比较）或双引号字符串（按文本精确比较）。
- 结果输出到 stdout，为单个 JSON 对象：
  - 普通查询：`columns` 为列名、`rows` 为命中行（按 CSV 原始行序）、`row_count` 为行数。
  - 聚合查询：`columns` 为 SELECT 中的原始表达式文本，`rows` 为单行结果，`row_count` 恒为 1。
- 数字字段以 JSON 数值表示，其余以 JSON 字符串表示。
- 执行按至多 1024 行的批次完成过滤、投影与聚合，且只读取 SELECT 与 WHERE 涉及的列。
- 不支持 OR、其他函数、通配符列、缺少 FROM 或其他子句；不写入任何缓存或派生文件。

错误约定：表文件不存在抛 `FileNotFoundError`；SQL 无法解析或使用不支持的语法抛
`ValueError`；引用不存在的列抛 `KeyError`；数值比较或 `sum` 遇到无法按十进制数
读取的字段抛 `ValueError`。
